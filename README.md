## О продукте

**BINOM AI** — это Enterprise AI Copilot для автоматизации подготовки тендерной документации.

Продукт ориентирован на строительные компании, EPC-подрядчиков и инжиниринговые организации Казахстана, которые тратят десятки часов на ручную подготовку тендерных пакетов.

### Ключевая идея

Пользователь загружает **PDF или DOCX** с техническим заданием → BINOM AI автоматически:

- 📋 **Анализирует** документ и извлекает требования
- ⚠️ **Определяет риски** и несоответствия
- 📂 **Выявляет** недостающие документы
- ❓ **Задаёт уточняющие вопросы** через интерактивный чат
- 📝 **Генерирует** Коммерческое предложение
- ⚙️ **Генерирует** Техническую спецификацию
- ✉️ **Создаёт** Сопроводительное письмо
- 📥 **Экспортирует** финальные документы в DOCX / PDF

## Ключевые принципы разработки

### 1. AI-First
Все функции строятся вокруг возможностей AI. Интеллект — не надстройка, а ядро продукта.

### 2. Enterprise Quality
Каждая функция должна соответствовать требованиям корпоративных клиентов: безопасность, надёжность, аудит.

### 3. Human + AI Collaboration
AI не заменяет специалиста — он усиливает его. Пользователь всегда в контроле.

### 4. Kazakhstan First
Локализация под казахстанский рынок: язык, нормативы, форматы документов ГОСТ/СНиП.

### 5. Scalable Architecture
Архитектура рассчитана на рост: от 1 компании до тысяч организаций.

### 6. Zero Frontend Changes
Frontend зафиксирован. Вся архитектурная работа ведётся на уровне backend, AI и API.

## Правила проекта

> ⚠️ **ВАЖНО: Разработка кода запрещена до полного завершения документации.**

1. Каждый документ должен быть **полностью завершён** перед переходом к следующему
2. Каждое архитектурное решение должно **соответствовать существующему Frontend**
3. Frontend **не изменяется** — только интеграция через API
4. Все решения должны быть **масштабируемыми** и готовы к production
5. Документы пишутся на уровне **Senior Product Team**
