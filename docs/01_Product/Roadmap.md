## Фаза 1: MVP Core

**Срок:** 2026-07-21 — 2026-08-31 (6 недель, 3 спринта по 2 недели)  
**Статус:** ⏳ Ожидает  
**Цель:** Рабочий продукт с core функциональностью, готовый для первых пользователей

### Sprint 1 — Фундамент (недели 1–2)

**Цель спринта:** Работающая платформа с авторизацией и управлением проектами

| Категория | Функции |
|-----------|---------|
| **Инфраструктура** | Docker setup, CI/CD pipeline, Supabase init, переменные окружения |
| **Backend** | FastAPI app skeleton, health checks, middleware (CORS, auth, logging) |
| **Auth** | Регистрация, авторизация (JWT), сброс пароля |
| **Профили** | Профиль пользователя, профиль компании, загрузка логотипа |
| **Проекты** | CRUD проектов, статусы, список проектов |
| **Файлы** | Загрузка PDF/DOCX, хранение в Supabase Storage, валидация |
| **Frontend** | Подключение к API (не изменяя UI) |
| **Security** | RLS в Supabase, JWT middleware |

**Sprint 1 Velocity:** 27 Story Points  
**Definition of Done Sprint 1:** Пользователь может зарегистрироваться, создать проект и загрузить ТЗ.

---

### Sprint 2 — AI Core (недели 3–4)

**Цель спринта:** Рабочий AI-анализ и интерактивный чат

| Категория | Функции |
|-----------|---------|
| **AI Integration** | Подключение Gemini API, fallback на GPT-4o |
| **Document Parsing** | PDF парсинг (PyMuPDF), DOCX парсинг (python-docx), chunking |
| **AI Analysis** | Извлечение требований, рисков, gap-анализ, резюме |
| **Structured Output** | JSON-схемы ответов AI, валидация Pydantic |
| **AI Chat** | Система уточняющих вопросов, контекстное окно, история |
| **Async Processing** | Celery + Redis очереди для AI-задач |
| **WebSocket** | Real-time обновления статуса анализа |

**Sprint 2 Velocity:** 28 Story Points  
**Definition of Done Sprint 2:** AI анализирует реальное ТЗ и задаёт уточняющие вопросы.

---

### Sprint 3 — Document Generation (недели 5–6)

**Цель спринта:** Полная генерация и экспорт документов

| Категория | Функции |
|-----------|---------|
| **Document Generation** | Генерация КП, Тех. спецификации, Сопроводительного письма |
| **Templates** | Шаблоны документов с правильными стилями для РК |
| **Rich Text Editor** | Интеграция редактора в UI для редактирования документов |
| **DOCX Export** | python-docx экспорт с форматированием, логотипом |
| **PDF Export** | WeasyPrint / reportlab экспорт из HTML |
| **Notifications** | Toast-уведомления о завершении генерации |
| **Quality Feedback** | Кнопки 👍 / 👎 после генерации |
| **Error Handling** | Graceful fallback при ошибках AI, retry механизм |

**Sprint 3 Velocity:** 34 Story Points  
**Definition of Done Sprint 3:** Пользователь загружает ТЗ → получает полный тендерный пакет → скачивает DOCX/PDF.

---

### MVP Launch Checklist

```
□ Все Must Have User Stories реализованы
□ AI-анализ протестирован на 20+ реальных ТЗ строительной отрасли
□ Время генерации < 60 секунд на всех типичных документах
□ Экспорт DOCX корректно открывается в MS Word
□ Экспорт PDF корректно открывается и текст-searchable
□ Нет P1/P2 багов по результатам QA
□ Uptime > 99.5% за 14 дней в staging
□ 3+ тестовых пользователя из ЦА завершили UX testing
□ Security audit пройден (RLS, injection, auth)
□ Мониторинг подключён (uptime, errors, latency)
```

## Риски реализации roadmap

| Риск | Влияние | Митигация |
|------|---------|-----------|
| Задержка документации | Сдвиг всей разработки | Жёсткие дедлайны, параллельная работа |

| Регуляторные требования РК | Изменение архитектуры | Хостинг в РК с самого начала |
| Конкурент выходит на рынок | Давление на темп | Ускорить MVP, фокус на локализации |
